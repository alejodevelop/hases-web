# UX/UI Design Specialist Skill

This skill provides a structured approach to designing modern, user-centric, and aesthetically pleasing web applications, incorporating 2025 trends and best practices.

## Core Principles

1.  **User-Centricity**: Every design decision must solve a user problem. Understand the persona, context, and goal.
2.  **Simplicity & Clarity**: Reduce cognitive load. Use clear visual hierarchy, whitespace, and intuitive navigation.
3.  **Consistency**: Maintain a unified visual language (colors, typography, spacing, components) across the application.
4.  **Accessibility (a11y)**: Design for all users. Adhere to WCAG 2.2 AA standards (contrast, keyboard nav, screen readers).
5.  **Mobile-First**: Design for small screens first, then scale up. Ensure touch targets are at least 44x44px.
6.  **Performance**: Design for speed. Optimize assets and minimize layout shifts (CLS).

## 2025 Design Trends

*   **Dark Mode**: First-class citizen. Ensure contrast and reduce eye strain.
*   **Micro-interactions**: Subtle animations (hover, click, load) that provide feedback and delight without distraction.
*   **Bento Box Layouts**: Modular, grid-based layouts for dashboards and content-heavy pages.
*   **Glassmorphism**: Subtle, frosted-glass effects for depth and modern feel (use sparingly).
*   **AI-Driven Personalization**: Adaptive interfaces that change based on user behavior (if applicable).

## Workflow

### 1. Discovery & Analysis
*   Define the user and the problem.
*   Analyze existing solutions or competitors.
*   Identify key user flows.

### 2. Structure (UX)
*   **Wireframing**: Sketch the layout without detail. Focus on information architecture.
*   **Navigation**: Ensure logical hierarchy. Use breadcrumbs, clear menus, and search.
*   **Responsive Planning**: Define breakpoints (Mobile, Tablet, Desktop).

### 3. Visual Design (UI)
*   **Color Palette**: Define Primary, Secondary, Accent, and Neutral colors. Use semantic naming (e.g., `bg-primary`, `text-error`).
*   **Typography**: distinct font hierarchy (Display vs Body). Limit to 2 font families.
*   **Spacing**: Use a consistent scale (e.g., 4px grid).
*   **Components**: Build reusable atoms (buttons, inputs) before pages.

### 4. Interaction & Polish
*   Add hover/focus states to all interactive elements.
*   Implement transitions (e.g., specific `duration-300 ease-in-out`).
*   Check accessible contrast ratios.

### 5. Validation
*   **Heuristic Evaluation**: Does it follow Jakob Nielsen's 10 usability heuristics?
*   **Accessibility Audit**: Run Lighthouse or similar tools.
*   **Cross-Device Check**: Verify on real mobile and desktop devices.

## Resources & Tools

*   **Tailwind CSS**: For utility-first styling.
*   **Stitch**: For generating initial UI from text prompts.
*   **Material Symbols / Lucide**: For consistent iconography.
*   **Google Fonts**: For optimized web typography.
